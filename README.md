# claude-open

Slack 알림의 「열기」 링크를 Claude 데스크톱 앱(`claude://code/…`)으로 넘기는 정적 페이지. 폰은 웹 주소로 보낸다.

사용: `https://everyhandbook.github.io/claude-open/#session_XXXX` — `#` 뒤 값은 서버로 전송되지 않는다. 데이터·비밀 값 없음.

Remote Control이 없는 스레드(예약 작업 실행분 등): `#local_<uuid>` → PC 앱 `claude://claude.ai/epitaxy/local_<uuid>`로만 연다(폰은 안내 문구만).
